# PREDICTING-REMAINING-USEFUL-LIFE-OF-ROBOTIC-EQUIPMENTS
Built an end-to-end predictive maintenance solution for robotics manufacturing using time-series sensor data (vibration, temperature, torque, power). Applied ML models to estimate Remaining Useful Life (RUL), tracked experiments with MLflow, and deployed with Gradio to reduce downtime and improve reliability.


# Predictive Maintenance for Robotics Manufacturing

Live App: https://huggingface.co/spaces/Dunbarin/KATAOKA_RUL

## Description
Built an end-to-end predictive maintenance solution for robotics manufacturing using time-series sensor data to estimate Remaining Useful Life (RUL). Uses MLflow for experiment tracking and Gradio for deployment.
